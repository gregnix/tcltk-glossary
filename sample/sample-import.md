# Sample import format for glossary

This file demonstrates the Markdown format that
`tools/import_md.tcl` accepts.

## Sample Category

**sample_term**
- EN: English definition of the term.
- DE: Deutsche Definition des Begriffs.

**another_term**
- EN: Another definition.
- DE: Eine weitere Definition.

## Another Category

**third_term**
- EN: Third definition.
- DE: Dritte Definition.
